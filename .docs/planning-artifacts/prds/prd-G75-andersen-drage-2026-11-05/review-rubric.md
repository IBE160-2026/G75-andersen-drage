# PRD Quality Review — AI-Based Learning Assistant for Students (prd-G75-andersen-drage-2026-11-05)

Reviewed: `prd.md` (status final, updated 2026-11-12), `addendum.md`, the last entries of `.memlog.md`, the formative feedback `tilbakemelding-prd.md`, and the final UX spine `EXPERIENCE.md` (ux-G75-andersen-drage-2026-11-10), against `.claude/skills/bmad-prd/assets/prd-validation-checklist.md`. Stakes: solo graded IBE160 project, deadline 15 Dec 2026. The PRD sits at the top of the chain (UX, architecture, epics). Run at 2026-11-12. This replaces the 2026-11-05 review.

## Overall verdict
The update did what the feedback asked. Every item in 4.1–4.5, the mechanical findings and the §6 Proxy question has landed. The core-loop gaps from the last review are closed: FR-18 now has a rule that composes Rounds from shaky and new concepts plus a known share, with a worked test case. FR-4 and FR-10 settle caching and "Try again". Passages and Key Concept IDs are defined. Every message key the PRD cites exists in EXPERIENCE.md › Microcopy. There are no critical or high findings. The remaining risk is in §8.1. The cut-order text has some ambiguous wording. The Core tier leaves out Flashcard review (FR-13) and Consent (FR-5) even though it claims to be the UJ-3 loop, and the update added three FRs without saying what that costs against the scope warning in 4.1. Five new inline `[ASSUMPTION]` tags are also unindexed in a PRD marked final. None of this puts the thesis at risk. Each item is a one-paragraph fix. EXPERIENCE.md still carries the old UJ numbers, which is a known and expected drift.

## Decision-readiness — strong
The new §8.1 states the build tiers as decisions, sets a Should cutoff (2026-12-01), and makes Open Questions 1 and 3 explicit gates "before epics". §12 Change log maps each requirement to its decision or review fix. Requirement text no longer carries inline "Decision Dn" or "Review fix" references. The Proxy question from the feedback is answered as a decision: local only, in DR-1, NFR-3 and the addendum.

Two tensions are still unnamed. First, feedback 4.1 (high) said the scope was too large for one person. The update answers with a cut order but also adds FR-25 (non-cuttable, Tier 2), FR-26 and FR-27, which brings the total from 24 to 27 FRs, and the PRD does not acknowledge this. Second, the earlier finding that there is no fallback if strict matching misses SM-3 is still open.

### Findings
- **[medium]** The update grows scope against feedback 4.1 without naming the trade-off (§8.1 Tier 2 "FR-4, FR-25 …"; §4.11 FR-25–27) — FR-25 'Dine notater' is a new surface that can never be cut, and it is built together with FR-4. The PRD does not say what it displaces, or why it outranks the items that can be cut. An examiner who reads the feedback next to the update will look for that sentence. *Fix:* Add one sentence to §8.1. For example: "FR-25 replaces re-upload as the return path in UJ-2. If time is short, FR-25 falls back to FR-4 re-upload and moves to Cut first, before FR-15." Alternatively, state why it must stay.
- **[medium]** There is still no fallback if strict matching misses SM-3 (§9 SM-3, SM-C2; §8.3 "A fuzzy or 'weak' Quote match tier") — This is carried from the last review. The PRD forbids looser matching and requires an 80% pass rate, but it does not say what gives if the reference notes fall short. *Fix:* Add one line in §9: tune the prompt first, then revisit the model choice (OQ-1). Lowering the threshold is a PRD update with a recorded reason (DR-4).

## Substance over theater — strong

NFR-2, NFR-3 and NFR-8 now have concrete tests, scenarios or thresholds (feedback 4.5).

UJ-2 (3 shaky + 1 known) now follows from the rule, which fixes the core flaw in feedback 4.2. Counter-metrics SM-C1 and SM-C2 still protect the 80/20 bet and the exact-match decision.

## Done-ness clarity — adequate
The high findings from last time are resolved. FR-18 has a Round size, a selection rule, an Items-per-concept rule and a test case: 8 concepts, 3 shaky and 5 known gives n = 3, round(0.6) = 1, so the Round holds 4. The arithmetic checks out, and so does "2 in a full Round of 10" (round(1.6) = 2). FR-4 and FR-10 state that a below-minimum generation is not cached and that "Try again" bypasses the cache under NFR-5. FR-8's injection test can now fail. FR-22 and FR-24 have consequences. Edge-case gaps remain around FR-18's inputs and the new Consent and Arkiv flows.

### Findings
- **[medium]** Eligibility allows a concept with no Quiz Question, but FR-18 requires one (§3 "Not covered: … no surviving Flashcard or Quiz Question"; §4.3 FR-10; §4.8 FR-18 "exactly one Quiz Question"; UJ-1 "one question per Key Concept") — SM-1's wording ("at least one surviving Flashcard or Quiz Question") makes it clear that "not covered" means *neither* survived. So a concept with only Flashcards is eligible, yet FR-18 and FR-14 cannot give it a Quiz Question. The FR-18 pure function and its unit tests have no rule for this case. *Fix:* Add one FR-18 consequence: "A concept with no surviving Quiz Question contributes only its Flashcards; the Quiz has one question per concept that has one." Alternatively, define eligibility as "has at least one surviving Quiz Question".
- **[medium]** FR-18's inputs are not in the persisted data (§4.8 FR-18 "pure function of (Mastery States, last-shown times, Centrality Ranks)", "the least recently used is picked"; §4.9 FR-21 "Extracted Text, Study Set, Mastery States and Round progress") — Neither the last-shown time per concept nor the last-used Quiz Question per concept (needed for rotation) is listed in FR-21, and the rotation state is missing from the FR-18 function signature. FR-25 "last practiced" is also not in FR-21. *Fix:* Add "last-shown time per Key Concept, last-used Quiz Question per Key Concept, last-practiced time, archive state and Importance Level" to FR-21, and add the rotation state to the FR-18 signature.
- **[low]** It is unclear when the FR-7 minimum of 5 Summary Points is counted (§4.3 FR-7 "a response with fewer than 5 counts as a failed generation") — Is it counted before or after Summary Points are dropped for being over 40 words or failing the Quote Check? FR-10's floor covers only Flashcards and Quiz Questions. *Fix:* State it. For example: "fewer than 5 in the response is a failed generation (FR-8); fewer than 5 surviving after drops is shown as is" (or is treated as below minimum under FR-10).
- **[low]** FR-5 does not say what upload and paste do after Consent is declined (§4.2 FR-5) — EXPERIENCE › State Patterns › Consent declined says that input is still validated (FR-3) and then rejected with `err.demoOnly` in Demo Mode, or `consent.declined` otherwise. The PRD has no consequence for this, and it does not say whether FR-24 `err.noKey` or `consent.declined` wins when both apply. *Fix:* Add one FR-5 consequence that mirrors the UX rule and states the precedence.
- **[low]** Re-supplying the content of an archived Note is unspecified (§4.1 FR-4; §4.11 FR-26) — The PRD does not say whether the Note reconnects inside Arkiv, is restored to 'Dine notater', or generates again. *Fix:* Add one consequence to FR-26. For example: "supplying an archived Note's content restores it to 'Dine notater' with its history".
- **[low]** The order within each state in a Round is unstated (§4.8 FR-18 "ordered shaky first, then new, then known") — The PRD defines how concepts are selected, but not the order in which they are presented within a state. *Fix:* "Within each state, in selection order."
- **[low]** Untestable phrasings remain — This is carried from the last review: FR-6 "scales with Note length" and FR-16 "avoids jargon". *Fix:* Either give FR-6 a rule or keep only the 5–15 range, and move "avoids jargon" into the SM-2 spot-check rubric.

Alternatively, add an "Open assumptions" sub-list to §11 that names each location.
- **[medium]** The §8.1 cut-order text is ambiguous (§8.1 "items are cut from the bottom of the list in §8.1.3 first"; Tier 2 lists FR-15 and FR-2; Tier 3 "then FR-15; then FR-2") — "§8.1.3" does not exist as a section. "From the bottom of the list" can be read as cutting FR-2 first, which contradicts "in this order". FR-15 and FR-2 appear in both Tier 2 and Tier 3 without explanation.
